# Kaptan Qedy Instagram Reel

Primary export: ../instagram-reel.mp4. Run python social/reel-v2/render.py from the repository root to recreate it. Requires Pillow, NumPy and FFmpeg.

Visual direction: cinematic ship crossing a dark sea, restrained cyan and magenta accents, three typography beats (return, Twitch + Kick, schedule), no interface screenshots.

Background plate was created with the built-in imagegen tool using this prompt: “Vertical 9:16 cinematic background for a Turkish gaming streamer's return: a small sailing ship heading toward a luminous opening in storm clouds across a deep navy ocean, restrained blue, cyan and magenta atmospheric lighting, realistic game-cinematic detail, and dark negative space for animated typography. No people, logos, interface or text.”

The original ambient music is synthesized locally by render.py; no external music sample is used.
